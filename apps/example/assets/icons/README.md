# Icons

The example's icons: one SVG per icon, the file name is the icon name. `@hzblj/kara-ui`'s config plugin (through
`@hzblj/expo-native-icons`) turns each into an iOS asset-catalog image and an Android vector drawable at prebuild, and
writes their names into `native-icons.d.ts`.

These are [Material Symbols](https://github.com/google/material-design-icons) (Outlined, 400), copyright Google LLC,
Apache License 2.0.
